# DTI Enhance

A complete makeover for [Dress to Impress](https://impress.openneo.net): modern themes, a better My Items, Notes, Neofriends, My Tokens, Neopets imports and more.

## Install

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Open **[dti-enhance.user.js](https://raw.githubusercontent.com/Legacy-l/dti-enhance/main/dti-enhance.user.js)** and click **Install**.
3. Open [impress.openneo.net](https://impress.openneo.net).

In Chrome, if the script doesn't run, go to `chrome://extensions`, open Tampermonkey's **Details**, and turn on **Allow User Scripts**.

## Updates

Updates install automatically. Tampermonkey checks once a day. To get an update straight away, click the Tampermonkey icon, then **Check for userscript updates**.
